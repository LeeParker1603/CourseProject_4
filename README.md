# Сервис управления рассылками (Mailing Service)

Веб-приложение на фреймворке Django для автоматизации, планирования и отправки email-рассылок по клиентским базам. Проект спроектирован как изолированная CRM-платформа с разграничением ролей пользователей, интеграцией СУБД PostgreSQL и оптимизацией кэширования через Redis.

## Основной функционал

- **Интерфейс управления (CRUD)**: Полноценное управление Клиентами, Шаблонами сообщений и Рассылками через адаптивные веб-страницы Bootstrap 5.
- **Динамический пересчет статусов**: Статус актуальности рассылки ('Создана', 'Запущена', 'Завершена') рассчитывается в режиме реального времени на основе системных часов компьютера без ручного вмешательства.
- **Изоляция личных кабинетов**: Абсолютное разделение адресных книг и писем между пользователями. Пользователи не видят и не могут редактировать или отправлять письма по чужим базам данных.
- **Пакетное логирование (Batch)**: Логирование результатов отправки писем (`Успешно` / `Не успешно`) сохраняется в PostgreSQL одной транзакцией через оптимизированный метод `bulk_create`.
- **Авторизация по Email**: Кастомная модель пользователя `User` с регистрацией по почте, обязательным подтверждением аккаунта через одноразовую токен-ссылку и встроенным механизмом сброса паролей.
- **Модерация (Роль Менеджера)**: Кастомная группа "Менеджеры" имеет право просматривать общую аналитику и принудительно блокировать/отключать любые рассылки или пользователей в системе (без права изменения приватных данных).
- **Высокая производительность**: Главная страница со счетчиками статистики полностью оптимизирована путем кэширования данных в оперативной памяти **Redis**.

## Стек технологий

- **Backend**: Python 3.12+, Django 6.1
- **Database**: PostgreSQL (современный драйвер `psycopg` версии 3)
- **Caching & Broker**: Redis
- **Frontend**: HTML5, CSS3, Bootstrap 5 (локальные статические библиотеки для автономной работы)

## Установка и развертывание проекта

### 1. Подготовка окружения и зависимостей
Убедитесь, что вы находитесь в корневой директории проекта:
```bash
python -m venv .venv
# Для Windows:
.venv\Scripts\activate
# Для Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Настройка конфигурации `.env`
Создайте в корне файл `.env` и укажите параметры подключения (используйте только латинские символы без пробелов):
```text
SECRET_KEY='django-insecure-ваша_секретная_строка'
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1

DB_NAME=mailing_db
DB_USER=postgres
DB_PASSWORD=ваш_пароль_postgres
DB_HOST=127.0.0.1
DB_PORT=5432

EMAIL_HOST=smtp.yandex.ru
EMAIL_PORT=465
EMAIL_HOST_USER=ваша_почта@yandex.ru
EMAIL_HOST_PASSWORD=ваш_16_значный_пароль_приложения_яндекс
EMAIL_USE_SSL=True
```
*Примечание: в настройках вашей Яндекс.Почты во вкладке «Почтовые программы» должна быть обязательно включена галочка доступа по протоколу IMAP/SMTP.*

### 3. Развертывание таблиц в PostgreSQL
Перед запуском создайте пустую базу данных с именем `mailing_db` в pgAdmin.
```bash
python manage.py makemigrations users
python manage.py makemigrations mailing
python manage.py migrate
```

### 4. Создание системных ролей и Администратора
```bash
# Автоматическое создание группы Менеджеры и привязка прав доступа из ТЗ
python manage.py create_manager_group

# Создание Суперпользователя (вход будет по Email)
python manage.py createsuperuser
```

### 5. Старт серверов
Убедитесь, что сервер Redis запущен на порту 6379, после чего запустите Django:
```bash
python manage.py runserver
```
Проект откроется по адресу: [http://127.0.0](http://127.0.0)

## Работа планировщика (Автоматический запуск)

Для полной автоматизации процесса отправки рассылок без участия пользователя, раз в 5-15 минут должен выполняться фоновый консольный скрипт:
```bash
python manage.py run_mailings
```
Данный скрипт сверяет текущее время с заложенными интервалами в базе данных PostgreSQL и осуществляет массовую отправку писем по актуальным триггерам.
